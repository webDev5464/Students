# 📡 JavaScript Task – Fetch and Display API Data

## 🔧 Task Description

Create a simple web application using **HTML** and **JavaScript** that performs the following:

1. Use the following public API:
   - API Endpoint: `https://jsonplaceholder.typicode.com/todos`

2. Create an **async function** in JavaScript to fetch data from the above API.

3. Convert the fetched response to **JSON**.

4. Display the data on the **webpage** using DOM manipulation.
   - Show each todo's **title** inside any HTML tag (like `<p>`, `<li>`, etc.).

5. All DOM changes should be done using **JavaScript**, not directly written in HTML.

6. Add a **try...catch block** to handle errors.
   - If an error occurs during fetch, log the **error name** in the console.

## 💻 Technologies to Use

- Plain HTML
- Plain JavaScript (No libraries or frameworks)

## 🎯 Objective

- Learn how to use the Fetch API.
- Understand async/await structure.
- Use DOM methods to update webpage content dynamically.
- Implement basic error handling.

## ✅ Bonus (Optional)

- Display only those todos where `completed` is `false`.
- Add basic styling using inline or internal CSS.
